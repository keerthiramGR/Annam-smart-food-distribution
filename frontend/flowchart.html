HOW THE ANNAM WEBSITE WORKS — SCREENS AND THE DETAILS ASKED (UPDATED)
BROWSER (FRONTEND CLIENT)
1. HOME PAGE — 4-DOOR ROLE GATEWAY
User selects a role: Food Donor | Recipient Shelter | Super Administrator | Delivery Driver
2a. DONOR PORTAL
Details asked:
  • Donor / kitchen entity
  • Food name and category
  • Number of portions
  • Quality condition
  • Shelf-life (hours) → use-by
  • Dietary type & storage
  • Pickup location (Erode)
Shows: Donation listing status (Pending / Approved)
2b. RECIPIENT PORTAL
Details asked:
  • Recipient organization (shelter / care home)
  • Approved food batch chosen
  • Portions required
  • Delivery instructions
Shows: Approved batches, Dijkstra road route & km, booking tracking, ETA
2c. ADMIN CONSOLE
Decisions / inputs:
  • Approve / reject donation
  • Approve / reject booking
  • Run multi-criteria check
  • Confirm & lock allocation
  • 1-click fleet dispatch
Shows: Review queues, fleet status, Erode road map & Dijkstra polyline
2d. DRIVER PORTAL
Decisions / inputs:
  • Select active fleet vehicle
  • Mark food picked up & depart
  • Confirm delivery handover
Shows: Active mission card, Stop 1 Pickup, Stop 2 Drop-off, live GPS turn-by-turn HUD

EXPRESS.JS REST API BACKEND (/api)
donationRoutes • authRoutes
• Receive donor listing form
• Validate use-by time & portions
• Self-registration for new donors & shelters
bookingRoutes • vehicleRoutes
• Receive portion booking requests
• Fleet vehicle registry (Tata Ace EV, etc.)
• Filter bookings by shelter ID
adminRoutes • routingRoutes
• Safety review & allocation decisions
• Driver delivery handover status update
• Erode 15-sector Dijkstra shortest paths
↕ ↕ ↕
SERVICES + DATA REPOSITORY
allocationService.js
1. FEFO: earliest use-by first
2. Donation approved? (Admin verified)
3. Stock sufficient? (demanded ≤ avail)
4. Vehicle available + capacity?
5. Deadline met? (transit ≤ shelf-life)
dijkstraService.js
• Least-time & shortest km route on the 15-location weighted Erode graph (graphData.js)
• 24 real road segments (SH 96, NH 544)
• Travel time divided by vehicle speed factor
• Continuous GPS polyline waypoints
repository.js • initialData.js
• In-memory fast datastore records: 5 donors, 12 shelters, food batches, bookings, vehicles
• Stock deducted atomically only after every feasibility check passes
• Immutable audit event logger

OUTPUT TO THE SCREENS: allocation status ➔ Dijkstra route & ETA ➔ stock balance ➔ live driver GPS navigation ➔ delivery confirmation
